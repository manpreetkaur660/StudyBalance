# StudyBalance – Initial Project Setup

StudyBalance is a web-based study planner prototype for university students. It is intended to support task organisation, deadline management, study progress and study-life balance.

## Current Version

This repository contains the **initial project setup** only. It includes the base page, responsive styling, JavaScript connection and placeholders for planned features. The complete functionality will be added in the final development commit.

## Planned Features

- Dashboard
- Task planner
- Deadline reminders
- Study timer
- Progress tracking
- Wellbeing support
- Browser LocalStorage

## Technologies

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub Pages
